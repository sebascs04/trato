# Idiomas de Trato

La interfaz conectada utiliza español (`es`) e inglés (`en`). El perfil permite elegirlos; también se puede elegir antes de iniciar sesión. La preferencia se guarda en `localStorage` con la clave `trato:ui-language`, por navegador. No es todavía una preferencia sincronizada entre dispositivos. La primera visita usa español.

Cambiar el idioma recarga la interfaz para reinicializar los módulos con el catálogo seleccionado. La navegación privada existente conserva el cliente, proyecto, pestaña y revisión autorizados. Ensayos conserva su propia ruta. La recarga no envía correos, no crea versiones ni ejecuta pagos.

## Cómo añadir textos

- Importar `uiText`, `uiLocale` o `uiLanguage` desde `i18n.mjs`.
- Añadir cada clave a `locales/es.mjs` y `locales/en.mjs`. Las claves nuevas deben describir su función; las etiquetas migradas conservan su texto español como clave.
- Usar parámetros (`uiText('practice.level',{value:3})`) y mantener los mismos nombres en ambos catálogos.
- Formatear fechas/importes con `Intl` y `uiLocale()`. El idioma no cambia la moneda ni las autorizaciones.
- Usar `npm run i18n:check`, incluido en `npm run check`, para comprobar paridad, parámetros y referencias literales. Las claves dinámicas necesitan cobertura explícita.
- Una clave, parámetro o idioma no soportado produce un error; no se sustituye por otro idioma.

La localización inicial del HTML se ejecuta una vez, antes de montar datos privados. Los módulos conectados usan traducciones explícitas al renderizar. Nombres, contratos, solicitudes, citas y contenido de correos se conservan exactamente como fueron guardados. Los mensajes de diagnóstico recibidos del servidor pueden conservar su idioma de origen; no se traducen datos arbitrarios con coincidencias de texto.

Las vistas antiguas de ejemplo en `app.js` y `graph-preview.mjs` conservan contenido histórico en español. El mapa conectado usa `graph-live.mjs`. No usar las vistas de ejemplo como alternativa ante un fallo conectado.

La política permanente para cambios futuros está en `AGENTS.md`.
