# 2. Get paid for each deliverable

Each stage of the plan is paid after the client approves its delivery, so this folder holds one confirmation per deliverable.

| File | When to upload it |
| --- | --- |
| `deliverable-1-acknowledgment.pdf` | Sending deliverable 1 to the client (USD 180) |
| `deliverable-2-acknowledgment.pdf` | Sending deliverable 2 to the client (USD 300) |
| `deliverable-3-acknowledgment.pdf` | Sending deliverable 3 to the client (USD 120) |

Step 4 of the [guide](../README.md#4-get-paid-for-each-deliverable) shows where each file goes in Trato.
