# 6. Answer a PayPal dispute

A dispute needs no file from this folder, because TeTrato answers it with the records the project already has: the stage's terms, the delivered file, the client's approval and the PayPal payment.

1. Pay any deliverable or addendum as the client.
2. Open a dispute on that payment as the buyer at https://www.sandbox.paypal.com/resolutioncenter (**Report a Problem**).
3. A few minutes later, Trato's home page shows **A client opened a PayPal dispute**. Open it and click **Prepare response with TeTrato**.

You review the response before **Send to client**. Step 8 of the [guide](../README.md#8-answer-a-paypal-dispute) has the details.
