# 1. Start a new project

Café Aurora wants a five-section website, and this folder holds the two documents that start the project in Trato.

| File | When to upload it |
| --- | --- |
| `01-initial-conversation.pdf` | When you create the project: TeTrato reads it and proposes the deliverables and staged payments |
| `02-initial-agreement.pdf` | When Trato asks for the confirmed initial agreement |

Step 3 of the [guide](../README.md#3-start-a-new-project) shows where each file goes in Trato.
