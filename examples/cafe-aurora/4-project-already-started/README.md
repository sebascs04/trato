# 4. Bring in a project that already started

Alex and Lucy began the website before using Trato, and the first stage is already done and paid. With these documents, TeTrato plans only the work that is left.

| File | When to upload it |
| --- | --- |
| `01-initial-agreement.pdf` | Upload it as **Initial agreement** in **New project → The project is already underway** |
| `02-deliverable-1-acknowledgment.pdf` | Upload it as **Delivery or acceptance**: it proves stage 1 is finished |
| `03-project-status-before-trato.pdf` | Upload it as **Reference**: it states what is done, paid and pending |

TeTrato then proposes a plan for the two remaining stages, USD 420 in total. Step 6 of the [guide](../README.md#6-bring-in-a-project-that-already-started) walks through every click.
